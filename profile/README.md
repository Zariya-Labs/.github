# Zariya Labs

**Founder-led custom software studio in Kathmandu, Nepal.**
We design and build web apps, mobile apps and backend systems for startups, agencies and growing businesses in fixed-fee, two-week sprints. You work directly with the engineer building your product, and you own the code.

[zariyalabs.com.np](https://zariyalabs.com.np) · [Clutch](https://clutch.co/profile/zariya-labs)

## What we build

- Business platforms and internal tools
- SaaS products and MVPs
- Cross-platform mobile apps
- Billing, payments and ledger systems
- Data pipelines and geospatial platforms
- Deployment, CI/CD and cloud setup

## How we work

1. **Scope first.** Acceptance criteria are agreed before we start.
2. **Two-week sprints.** Regular written updates and recorded demos.
3. **Full handover.** Repository, infrastructure scripts, tests and documentation are transferred to you.
